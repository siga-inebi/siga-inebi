# Backend Foundation

Espacio reservado para proyecto Django + Django REST Framework.

Estado actual:

- Fundacion ejecutable inicial creada.
- API base disponible bajo `/api/v1/`.
- Modelos fundacionales y migraciones iniciales incluidos.

Restricciones:

- Desarrollo local inicial con SQLite.
- Pruebas automatizadas, staging y produccion con PostgreSQL.
- Acceso a datos via ORM salvo justificacion tecnica documentada.
