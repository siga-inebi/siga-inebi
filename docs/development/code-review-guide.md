# Code Review Guide

## Revisar primero

- Riesgos de negocio.
- Riesgos de autorizacion y privacidad.
- Falta de pruebas.
- Violacion de ADR.
- Puntos sin trazabilidad a RF/RNF.

## Preguntas clave

- Cambio responde a requerimiento identificable.
- Regla vive en dominio correcto.
- Historia y auditoria se conservan.
- PostgreSQL sigue siendo compatible.
- Documentacion se actualizo.
