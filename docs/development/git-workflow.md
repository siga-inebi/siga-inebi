# Git Workflow

## Flujo base

1. Crear rama corta desde rama base del equipo.
2. Referenciar requerimiento o decision.
3. Implementar cambio pequeno y verificable.
4. Agregar o actualizar pruebas.
5. Actualizar trazabilidad.
6. Abrir Pull Request.

## Convenciones sugeridas de ramas

- `feat/<topic>`
- `fix/<topic>`
- `docs/<topic>`
- `chore/<topic>`

## Reglas

- No hacer push de secretos.
- No mezclar cambios no relacionados.
- No marcar RF como completado sin pruebas.
