# Code of Conduct

## Compromiso

Proyecto promueve colaboracion respetuosa, revision honesta y documentacion clara. Se espera trato profesional entre desarrolladores, revisores y agentes de IA.

## Conducta esperada

- Discutir ideas, no personas.
- Señalar riesgos con evidencia.
- Pedir aclaracion cuando exista ambiguedad material.
- Proteger privacidad y seguridad institucional.
- Mantener trazabilidad de decisiones tecnicas.

## Conducta no aceptable

- Incluir secretos o datos reales.
- Cambiar alcance sin documentarlo.
- Omitir pruebas deliberadamente en cambios funcionales.
- Borrar historial auditable.
- Usar lenguaje discriminatorio o intimidante.

## Aplicacion

Responsable propietario del repositorio definira proceso formal de aplicacion y escalamiento.
